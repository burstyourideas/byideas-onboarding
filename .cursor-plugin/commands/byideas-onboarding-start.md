# /byideas-onboarding-start - Set Up the Burst Your Ideas Agent Stack

Start the guided onboarding. Load the `byideas-onboarding` skill and follow it
from Step 1. Run only one step at a time and wait for the user to confirm each
before moving on. Never ask for, store or print tokens, passwords or API keys.
In Cursor this command is `/byideas-onboarding-start`. In Claude Code and Cowork
the same guide is `/byideas-onboarding:start`.
